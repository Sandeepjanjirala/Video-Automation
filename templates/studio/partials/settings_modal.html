Settings & providers

API keys in your .env file are the defaults. Type a key below to use a different one (it is saved in this studio's data folder); leave a field blank to keep the key in use. Online actions send your topic/script or search terms to the chosen provider.

Gemini API key Needed for research and AI drafts.

Backup Gemini models Comma-separated, tried in order when the model above is out of quota, busy or retired. Each model has its own free daily quota.
Password for phone and other devices This computer never needs it. Phones and other computers sign in with it (start the studio with START_PHONE_ACCESS.bat). Leave blank to keep the current password.
Maximum Gemini API requests per UTC day A request-count limit, not a financial spending cap.
